## 📌 About This Project

Valorant Cheat 2026 is an external companion for players who want better awareness during matches.
It combines precise aim assistance, visual overlays, and adjustable profiles into one lightweight build.
Runs outside the game process — no injection, no clutter.

## 🧩 Included Modules

- 🎯 Aim assistant with smoothness control
- 👁️ Enemy ESP through obstacles
- 📡 Position and distance markers
- 🧠 Spray pattern control
- 🔧 Custom profiles per weapon
- 🔄 Background auto-update
- 🎨 Lightweight on-screen menu
- ⚙️ Hotkey customization

## 🖥️ Requirements

- Windows 10 / 11 (64-bit)
- Intel Core i3 or AMD equivalent
- 8 GB RAM or more
- Microsoft Visual C++ Redistributable
- Administrator rights
